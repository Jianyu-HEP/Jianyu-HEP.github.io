# Jianyu Zhang — academic website

English: https://jianyu-hep.github.io/

Chinese: https://jianyu-hep.github.io/zh/

Static HTML, CSS and JavaScript. Publish from main / (root) using GitHub Pages.

This repository contains the generated public website. Build the maintained source with tools/build_zh.py, tools/build_pages.cjs and tools/build_release.py before updating these files.

Experimental photographs, published figures and conference posters retain their original credits and source links on the website. This is a personal website, not an official collaboration site.
