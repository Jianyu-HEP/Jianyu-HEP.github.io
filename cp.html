BESIIIPRECISION CP TESTS

Precision CP tests

Question

Do hyperons and antihyperons obey the same decay laws?

Method

I compare decay parameters using multidimensional angular fits to entangled Λ and Ξ⁰ pairs, efficiency calibration and systematic validation. Complementary hyperon-to-neutron decays extend these tests.

Result · Entangled Λ pairs · PRL 2022ACP = (−2.5 ± 4.6 ± 1.2) × 10−3

Statistical and systematic uncertainties, respectively. The result is consistent with CP symmetry.

My contribution to this programme

I played leading roles in precision measurements, including multidimensional efficiency calibration and systematic validation at the 10⁻³ precision scale.
